# Spaceship web application

This folder contains the Next.js application. The full project README, including setup, architecture, the AI approach, assumptions, limitations, and the testing story, lives at the repository root: see [`../README.md`](../README.md).

Quick start:

```bash
npm install
cp .env.example .env.local   # fill in API keys
npm run dev
```

Useful scripts: `npm test` runs the engine unit tests, `npm run seed` loads Supabase after the migrations, `npm run build` produces the production build.
